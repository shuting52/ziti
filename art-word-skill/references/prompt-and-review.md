# Prompt and Review：提示词与审核

## 提示词结构

提示词必须包含：

1. 画幅和构图
2. 文字内容
3. 字体类型
4. 字形结构
5. 排列方式
6. 立体结构
7. 材质
8. 色彩
9. 光影
10. 背景
11. 应用场景
12. 清晰度
13. 文字准确性
14. 负面提示词

## 审核清单

- [ ] 文字内容与用户输入一致
- [ ] 文字数量正确
- [ ] 没有额外文字
- [ ] 没有乱码
- [ ] 没有英文替换中文
- [ ] 字体与应用场景匹配
- [ ] 材质描述具体
- [ ] 光源方向明确
- [ ] 背景不干扰主体
- [ ] 文字没有被裁切
- [ ] 没有复制参考图
- [ ] 适合商业使用

## 中文文字生成建议

如果 AI 无法稳定生成中文，先生成字体造型和材质，再使用 Photoshop、Figma、Illustrator 或 Canva 添加准确文字。
